# Pandas Practice

## About This Repository
This repository contains my Python Pandas practice exercises as I learn data manipulation and data analysis. It documents my learning progress through practical coding examples.

## Topics Covered
- DataFrame creation and basic operations
- Selecting rows and columns using `loc` and `iloc`
- Filtering data using conditions
- Handling missing values
- Adding, updating, and dropping columns
- Sorting data with `sort_values()`
- Grouping data with `groupby()`
- Aggregating data using `mean()`, `sum()`, `count()`, `min()`, and `max()`
- Finding top students overall and within each class
- Basic statistics and data analysis

## Dataset
I use a student dataset for practice, including columns such as student name, class, age, marks, attendance, gender, and city.

## Technologies Used
- Python
- Pandas
- NumPy (where applicable)

The purpose of this repository is to strengthen my Python data analysis skills through hands-on practice and to document my learning journey.
